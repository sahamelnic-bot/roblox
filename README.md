# Roblox Trend Tracker

Бот, який щогодини знімає онлайн ігор з головної Roblox і шукає **ті, що ростуть найшвидше**, а не найбільші.

## Що рахує

| Блок | Як | Навіщо |
|---|---|---|
| 🚀 Ракети | ріст онлайну vs **той самий час учора**, мінус медіана ринку | головний сигнал; порівняння з учора прибирає добовий цикл (вечір у США – пік) |
| ⚡ Ранній сигнал | ріст за 6 год, мінус медіана ринку за 6 год | ловить старт раніше, але шумніше |
| 📈 Прискорення візитів | нові візити за добу / за попередню добу | показує, що гра розганяється, а не просто тримає онлайн |
| 🆕 Нові ігри | створені ≤ 30 днів тому з онлайном ≥ порогу | свіжі механіки |
| 🧠 Тренди тем | групує ігри за словами в назвах (`brainrot`, `tsunami`, `steal`...) і рахує сумарний ріст | видно не одну гру, а **механіку/тему**, яку вже клонують |

Ігри з онлайном < `MIN_CCU` (300 за замовчуванням) ігноруються – там +500% це 2→12 гравців, шум.

## Запуск

Працює сам на GitHub Actions (безкоштовно), нічого не треба ставити.

1. Цей репо має бути **гілкою за замовчуванням** (Settings → Branches), бо `schedule` в Actions працює лише на default-гілці.
2. Settings → Actions → General → Workflow permissions → **Read and write**.
3. (Опційно) Telegram:
   - створи бота через [@BotFather](https://t.me/BotFather), отримай токен;
   - напиши боту будь-що, потім відкрий `https://api.telegram.org/bot<TOKEN>/getUpdates` і візьми `chat.id`;
   - Settings → Secrets and variables → Actions → додай `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.
4. Actions → `roblox-trends` → **Run workflow** – перший знімок.

Дайджест у Telegram приходить раз на добу о ~09:00 за Києвом. Повний звіт завжди лежить у [`reports/latest.md`](reports/latest.md).

**Перші осмислені «ракети» будуть через ~24 год**, прискорення візитів – через ~48 год: потрібна історія.

## Локально

```bash
python -m tracker.main run            # знімок + звіт
python -m tracker.main report         # тільки звіт з наявних даних
python -m tracker.main run --notify   # + Telegram (потрібні env-змінні)
python -m unittest discover -s tests -t .
```

Тільки стандартна бібліотека Python 3.10+.

## Дані

- `data/snapshots/YYYY-MM-DD.csv` – сирі знімки (відкриваються в Google Sheets).
- `data/watchlist.txt` – ігри, які трекати завжди (свої ігри, конкуренти).
- Ігри, що випали з головної, трекаються ще 3 дні, щоб не губити динаміку.

## Обмеження (чесно)

- Ендпоінти Roblox (`explore-api`, `games.roblox.com`) публічні, але **недокументовані** – Roblox може змінити формат. Парсер пошуку ігор рекурсивний, щоб пережити дрібні зміни, але якщо щось зламається – дивись лог в Actions.
- Бачимо тільки те, що Roblox показує на головній (кілька сотень–тисяч ігор). Гра, яка росте з нуля десь у глибині, з'явиться, коли потрапить у Up-and-coming / Trending.
- Це сигнал «куди дивитись», а не рішення. Далі – руками: зайти, пограти, зрозуміти механіку за 5 секунд.
