# Trend Tracker – Roblox · Steam · Twitch · YouTube

Щогодини збирає онлайн ігор і перегляди відео й шукає **те, що росте найшвидше**, а не найбільше. Раз на добу шле дайджест у Telegram.

## Джерела

| Джерело | Звідки | Ключ | Що дає |
|---|---|---|---|
| 🟥 Roblox | публічні `explore-api` + `games.roblox.com` | не треба | онлайн, візити, лайки, вік гри |
| 🟦 Steam | офіційний Steam API + store + SteamSpy | не треба | онлайн, дата релізу, ціна, жанр |
| 🟪 Twitch | офіційний Helix API | `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` (опційно) | глядачі по іграх – найраніший сигнал для Steam |
| ▶️ YouTube | Data API, стежимо за каналами з `config/youtube_channels.txt` | `YOUTUBE_API_KEY` | відео-хіти й теми в назвах |

SteamDB і TikTok не використовуються: у SteamDB немає API й скрапінг заборонений, TikTok відкладено.

## Метрики

| Метрика | Як | Навіщо |
|---|---|---|
| **Множник 24 год** | онлайн зараз / онлайн **у той самий час учора** | прибирає добовий цикл (вечір у США – пік) |
| **Швидше ринку** | (1+ріст гри) / (1+медіанний ріст ринку) − 1 | вихідні й канікули піднімають усіх, нам треба тих, хто швидше |
| **Поріг** | Roblox ≥ 300 онлайн, Steam ≥ 200, Twitch ≥ 500 глядачів | 2→20 гравців – шум |
| **Діб росту** ↑↑↑ | скільки діб поспіль росте (до 3) | відсіює разові сплески від реклами чи одного відео |
| **Ранній сигнал** | те саме за 6 год | раніше, але шумніше |
| **Вік** | днів від створення / релізу | нова гра з ростом = нова механіка |
| **Сесія** (Roblox) | онлайн × 1440 / візити за добу ≈ хв на візит | заходять і сидять чи заходять і тікають |
| **Сплеск від оновлення** | гра > 60 днів, оновлена < 3 днів тому, +50% | позначається окремо, не «ракета» |
| **Теми** (Roblox) | сумарний ріст ігор з одним словом у назві + скільки нових за 14 днів | механіка, яку вже клонують; багато клонів – пізно |
| **Відео-хіт** (YouTube) | перегляди свіжого відео ÷ звичайний результат каналу (медіана відео 3–14 днів) | 200% = за добу вже вдвічі більше, ніж канал зазвичай має за тиждень |
| **🔥 Збіги** | слово росте одночасно в ≥ 2 джерелах | найсильніший сигнал |

## Запуск (GitHub Actions, безкоштовно)

1. Ця гілка має бути **default** (Settings → Branches) – `schedule` працює лише на ній.
2. Settings → Actions → General → Workflow permissions → **Read and write**.
3. Settings → Secrets and variables → Actions → **Secrets**:
   - `YOUTUBE_API_KEY` – [Google Cloud Console](https://console.cloud.google.com/) → новий проєкт → APIs → увімкнути *YouTube Data API v3* → Credentials → API key.
   - `TELEGRAM_BOT_TOKEN` – від [@BotFather](https://t.me/BotFather).
   - `TELEGRAM_CHAT_ID` – напиши боту, відкрий `https://api.telegram.org/bot<TOKEN>/getUpdates`, візьми `chat.id`.
   - (опційно) `TWITCH_CLIENT_ID` + `TWITCH_CLIENT_SECRET` – [dev.twitch.tv/console](https://dev.twitch.tv/console) → Register application.
4. (опційно) **Variables** → `MIN_CCU` – поріг онлайну Roblox (300 за замовчуванням).
5. Actions → `trends` → **Run workflow**.

Джерело без ключа просто пропускається. Якщо джерело впало, інші працюють, а у звіті з'являється ⚠️.

**Звіт:** гілка `tracker-data` → `reports/latest.md`. Там же сирі CSV (відкриваються в Google Sheets).

**Коли буде сенс:** ріст за 6 год – через 6 год, ракети – через добу, «діб росту» й прискорення – через 2–3 доби, YouTube-хіти – коли в каналів назбираються відео старші за 3 дні (одразу, якщо канали активні).

## Налаштування

- `config/roblox_watchlist.txt` – universeId ігор, які трекати завжди (свої, конкуренти).
- `config/steam_watchlist.txt` – appid Steam-ігор.
- `config/youtube_channels.txt` – канали. Неправильні хендли бот покаже в лозі Actions.

## Локально

```bash
python -m tracker.main run --sources roblox,steam      # збір + звіт
python -m tracker.main report                          # тільки звіт
python -m unittest discover -s tests -t .
```

Тільки стандартна бібліотека Python 3.10+.

## Обмеження

- Roblox `explore-api` недокументований – може змінитись. Парсер рекурсивний, але якщо впаде, побачиш ⚠️.
- Бачимо тільки ігри з головних підбірок Roblox і публічних списків Steam (+ watchlist).
- Steam appdetails має ліміт ~200 запитів / 5 хв, тому мета нових ігор підтягується по 40 за запуск.
- YouTube: ~60 одиниць квоти за запуск при 20–50 каналах (ліміт 10 000/день).
- Це компас, а не рішення: далі – зайти, пограти, зрозуміти механіку.
